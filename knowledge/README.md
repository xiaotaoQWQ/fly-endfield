## 三句话概括这个项目

```
《终末地》画面  ──截屏──►  复眼感光细胞（光流）
                          │
                          ├──► 211,577 个神经元（MaleCNS 连接组，速率模型）
                          │        │
                          │        └──► 蘑菇体学习（多巴胺三因子，只改 KC→MBON）
                          │
                          └──► 下行神经元群体解码 ──► WASD / 鼠标 / 技能键
                                    │
                                    └──Interception 驱动──► 游戏
```

**两条底线**（任何改动都不能破坏）：
1. 它得**真的在控制那个角色**（不能是脚本在走、果蝇只做装饰）
2. 它得**真的能走到某个地方**（不能永远在原地打转）

**验证第 1 条的方法**：面板「对照组」里关掉「连接组」，
神经网络输出换成随机数，看行为变不变。

## 一句话记住的那些事

这些是**改错会出事**的：

- **读网络输出用 `w @ r[kc]`，不要用 `r[mbon].mean()`**
  （前者是网络对 MBON 的输出，后者是神经元自己的活动，两者不等价）

- **技能语义必须当"本能"写死**，不能让学习去发现
  （果蝇从画面上看不出"回血"和"格挡"的区别，"没挨打"不是信号）

- **抓屏是抓**屏幕**，不是抓游戏窗口**
  （DirectX 游戏 `PrintWindow` 返回全黑）→ 任何遮挡都是致命的

- **面板会遮住它自己要检测的东西**
  （「挑战成功」横幅就被叠加面板盖住了 → 改用左任务条）

- **长按不能 `sleep`**
  （1 秒 > 决策拍 400ms，会卡死整个主循环）→ 按下/抬起拆到不同拍

- **`ttk.Combobox` 悬停时会跟着滚轮变值**
  （用户滚滚轮路过面板，键位就被静默改掉了）

- **多步补丁的守卫要看整个补丁的最终状态**
  （`'_x' not in s` 被同一次补丁的前一步插入的 `_x` 挡住 → 定义没插、调用插了 → NameError）
