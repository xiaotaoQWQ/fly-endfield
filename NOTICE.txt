  二、使用前必读（注意事项）
--------------------------------------------------------------------------------

【1】必须以**管理员身份**运行
     键盘注入用的是 Interception 驱动，没有管理员权限**完全不生效**
     （表现：果蝇算得很欢，游戏里一个键都不按）。
     双击 exe 会弹 UAC，点「是」。
     不想提权可以用 --no-elevate，但那样它动不了游戏，只能看它"想"什么。

【2】游戏必须**已经开着**，且**不能最小化**
     程序启动时会检测终末地。没检测到的话「启动」按钮是灰的。

【3】★★★ 绝对不要有窗口压在游戏上面 ★★★
     这是最容易踩、最难查的坑。

     程序抓的是**屏幕**，不是游戏窗口（DirectX 游戏拿不到窗口画面）。
     所以任何压在上面的窗口，果蝇都会把它当成"游戏画面"读进去 ——
     而且**不报错、不崩溃、只是那个功能永远不触发**。

     实测踩过的坑：
       · 聊天窗口盖住连携技搜索区 → E 键永远检测不到 → 永远不放连携技
       · 聊天窗口盖住血条 → 血量读不到 → 自动挨打失效、大招永远不放
       · 叠加面板压住"任务完成"横幅 → 打完副本不给奖励

     这三个症状看起来毫不相关，根因是同一个。
     程序启动时会**自动检查并警告**，看到警告就把那些窗口挪开。

【4】建议用**无边框窗口**或**全屏**
     分辨率**任意**（16:9 / 16:10 / 21:9 都行），程序会自己适配。
     实测覆盖：1280×720 / 1600×900 / 1920×1080 / 1920×1200 /
              2560×1440 / 2560×1080 / 3840×2160 / 1680×1050

【5】游戏内按键要**对得上**
     面板最上面有一行「键位」，显示当前配置：
       普攻 · 技能①②③④ · 连携技 · 大招
     如果和游戏里的实际键位不一样，它就会一直按错键。
     ★ 键位在面板上改（下拉框）。

【6】进副本、打怪、结束时**不要动鼠标键盘**
     果蝇和你在抢输入。你一动，它算出来的东西就被你覆盖了。

【7】End 键 = **暂停**（原地暂停，点「启动」接着跑）
     不是重来一轮。想真正结束这一轮，点面板上的「停止」。


--------------------------------------------------------------------------------
  三、这是什么
--------------------------------------------------------------------------------

用一只真实果蝇的**全脑连接组**（MaleCNS v1.0，211,577 个神经元、
26,028,386 个化学突触）去驾驶《明日方舟：终末地》里的角色。

它不是"脚本帮你打游戏"。它是一个**行为艺术作品**：

  · 果蝇看到的东西 → 复眼感光细胞的信号
  · 它的"想法" → 211,577 个神经元按真实突触权重互相激发
  · 它的"情绪" → 多巴胺（打赢了给奖赏、挨打了给惩罚）
  · 它会饿 → 饥饿值上升 → 越饿越想扑上去
  · 它会学 → 蘑菇体（KC→MBON）突触按三因子规则改写
  · 它按下的键 → 真的传进游戏里

两条底线：
  ① 它得**真的在控制那个角色**（不能是脚本在走、果蝇只做装饰）
  ② 它得**真的能走到某个地方**（不能永远在原地打转）

面板里的「对照组」就是用来验证第 ① 条的：
把「连接组」关掉，神经网络输出换成随机数。如果关掉前后行为差不多，
那这两亿个突触就只是装饰 —— 那时候这个项目的前提就不成立。

--------------------------------------------------------------------------------
  五、出问题了怎么办
--------------------------------------------------------------------------------

同目录下的 **fly_app.log** 记录了全过程（点击、键位改动、技能选择、
大招、连携技、任务完成、报错）。**反馈问题时请把它附上。**

快速自查：

  · 游戏里一个键都不按
      → 没以管理员身份运行（看日志里有没有 "Interception" 那行）

  · 果蝇在乱按键 / 提示一直不消失
      → 面板最上面「键位」那行和游戏里的实际键位对不上

  · 连携技 E 永远不放
      → 检查连携技搜索区有没有被窗口挡住（启动时会警告）

  · 血量读不到 / 大招永远不放
      → 同上，血条区域被挡住了

  · 打完副本不给奖励
      → 「任务完成检测」**默认是关的**（靠屏幕认副本结束实测误触太多）。
        想试的话加 --mission 打开，并调面板里那组的参数

  · 界面卡住
      → 看日志尾部有没有异常堆栈

  · 想看它是不是真在起作用
      → 面板「对照组」里关掉「连接组」，再跑一轮对比
